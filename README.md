# 学习通 DDL 提醒 (astrbot_plugin_chaoxing_ddl)

AstrBot 插件 —— 自动登录学习通（超星）读取未交作业的截止时间，剩最后 N 天时通过 QQ 等已接入平台主动推送提醒。

## 功能

| 功能 | 说明 |
| --- | --- |
| 📥 自动抓取作业 DDL | 定时登录学习通，抓取所有课程未交作业的截止时间 |
| ⏰ 自定义提醒节点 | 配置「提前提醒天数列表」，如 `[2, 1]` = 剩最后 2 天提醒一次、剩最后 1 天再提醒一次，每条只推一次 |
| 🔐 登录方式自选 | 命令 `cxlogin` 交互选择：账号密码 / 手机短信验证码 / Cookie / 自动 |
| 📱 短信验证码登录 | 选「验证码登录」后插件发短信到你手机，你在聊天里回验证码即可，全程不用去网页 |
| 🖼️ 图形验证码兜底 | 网页登录被要求图形验证码时，自动把图片推到聊天窗口，回复 `cxcode 验证码` 完成 |
| 💾 登录态持久化 | 登录成功后保存 Cookie，重启免登录，减少触发验证码的机会 |
| 📋 每日汇总 | 每天固定时刻推送一份「未交作业一览」（可关闭） |
| 💬 手动查询 | 对机器人发「作业」即可查看当前未交作业清单 |
| 📚 课程查询 | 发「课程」列出我在学的所有课程；发「课程 2」或「课程 高数」看单门课的未交作业 |
| 📖 命令帮助 | 发 `cxhelp` 查看全部命令 + 当前运行状态（登录方式、绑定会话、提醒节点等） |
| 📌 会话绑定 | 在任意 QQ 群/私聊里发 `cxbind`，提醒就会推到该会话 |
| 🎓 考试提醒（可选） | 尽力抓取课程考试安排（依赖学校页面结构，可能取不到） |
| 🎯 课程过滤 | 可只监控指定课程，避免噪音 |

## 安装

在 AstrBot WebUI「插件市场 → 从仓库安装」中填入本仓库地址，或在「插件」页本地导入本目录。

依赖 `httpx`、`pycryptodome` 会在安装时自动装好。

**装完不用改任何配置**：直接在 QQ 里发 `cxlogin`，机器人会问你要手机号（和密码），配完自动开始巡检。详见下面「零配置使用」。

## 零配置使用（推荐）

WebUI 里的手机号 / 密码 / Cookie **全部留空也能用**，账号可以直接在聊天里配：

```
[你]     cxlogin
[机器人] 📱 还没有设置学习通账号，先把手机号告诉我：
        请直接回复 11 位手机号，例如 13800000000
[你]     13800000000
[机器人] ✅ 手机号已保存：138****0000
        🔐 请选择学习通登录方式：
        1️⃣ 账号密码登录（用已保存的手机号+密码，缺密码会提示你输入）
        2️⃣ 手机验证码登录（发短信到你手机，再回复验证码）
        3️⃣ Cookie 登录
        4️⃣ 自动
[你]     2
[机器人] 📱 验证码已发送至 138****00，请回复 cxcode 123456
[你]     654321
[机器人] ✅ 登录成功（手机验证码登录）
        后续巡检会默认使用该方式，可发「作业」或「课程」试试。
```

也可以分步来：`cxsetphone 13800000000` → `cxpwd 你的密码`，设完会自动启动巡检；
随时用 `cxaccount` 看当前账号状态（手机号脱敏显示）。

没配账号时插件**不会报错也不会空转巡检**，只会等你发命令。账号存在 `data/plugin_data/astrbot_plugin_chaoxing_ddl/data.json` 里（密码明文，注意别泄露该文件）。该目录不受插件重装/更新影响，旧版写在插件目录里的 data.json 会在启动时自动迁移过来。

## 配置（全部可选）

| 配置项 | 说明 | 默认 |
| --- | --- | --- |
| `phone` | 学习通手机号 | 留空，用 `cxlogin`/`cxsetphone` 设置 |
| `password` | 学习通密码 | 留空，用 `cxlogin`/`cxpwd` 设置 |
| `login_mode` | 默认登录方式：`auto` / `password` / `sms` / `cookie` | `auto` |
| `cookie` | 浏览器 Cookie，最稳的登录方式 | 空 |
| `captcha_timeout` | 验证码/等待回复超时（秒） | `180` |
| `remind_days_before` | 提前提醒天数列表，如 `[2, 1]` | `[2]` |
| `check_interval_minutes` | 巡检间隔（分钟），建议 30~120 | `60` |
| `push_targets` | 固定推送目标（一般用 `cxbind` 绑定即可） | 空 |
| `include_exams` | 是否检查考试 | `false` |
| `course_filter` | 只监控的课程关键词 | 空（全部） |
| `digest_hour` | 每日汇总时刻（0-23，-1 关闭） | `9` |
| `digest_days` | 汇总包含未来 N 天内的作业，0 = 全部 | `7` |

## 登录方式怎么选

发送 `cxlogin`，机器人会回一份菜单，回数字即可：

```
🔐 请选择学习通登录方式：
1️⃣ 账号密码登录（用配置里的手机号+密码）
2️⃣ 手机验证码登录（发短信到你手机，再回复验证码）
3️⃣ Cookie 登录（用已保存/配置的 Cookie，最稳）
4️⃣ 自动（先试 Cookie，再密码，需要时弹图形验证码）

回复数字或关键词（如 1 / 密码 / 短信 / cookie），120 秒内有效
```

| 方式 | 命令 | 适用场景 |
| --- | --- | --- |
| 账号密码 | `cxlogin 密码` | 知道密码；插件先走 APP 协议（通常不弹图形验证码），失败才回退网页协议 |
| 手机验证码 | `cxlogin 短信` | 忘记密码 / 密码登录被风控；插件发短信，你回 `cxcode 123456` |
| Cookie | `cxlogin cookie` 或 `cxsetcookie <整段Cookie>` | 长期无人值守最稳，一次配置能用很久 |
| 自动 | `cxlogin auto` | 默认；Cookie → 密码 → 必要时图形验证码 |

选定的方式会记在 `data.json` 的 `login_mode`，之后巡检默认用它；随时可以再发 `cxlogin` 改。

### 短信验证码登录流程

```
[你]     cxlogin 短信
[机器人] 📱 验证码已发送至 138****00
         请回复：cxcode 123456（6 位数字，直接发数字也可以）
[你]     654321
[机器人] ✅ 登录成功（手机验证码登录）
```

为防止误刷短信，同一号码 10 分钟内只会发一条。

### 图形验证码（网页登录兜底时出现）

```
[机器人] 🔐 学习通网页登录需要图形验证码（请输入验证码）
         [验证码图片]
         请回复：cxcode 验证码
[你]     cxcode a3F9
[机器人] ✅ 图形验证码已提交，正在重试登录…
```

输错会自动换一张新图再问一次，最多 3 轮。

### Cookie 怎么拿

1. 浏览器登录 https://i.chaoxing.com
2. F12 → Network → 任意请求 → Request Headers → 复制 `Cookie:` 后面的整段内容
3. 聊天里发 `cxsetcookie xxx=yyy; aaa=bbb`，或粘到 WebUI 配置的 `cookie` 项

插件会立即校验 Cookie；有效则直接登录并保存登录态。

## 指令一览

```
作业                   # 查询全部未交作业及截止时间
作业 全部              # 诊断：列出抓到的所有条目（含已完成）和状态原文
课程                   # 列出我的课程（带序号）
课程 2                 # 看第 2 门课的未交作业（也支持课名，如「课程 高数」）
cxhelp                 # 命令一览 + 当前运行状态（别名：帮助 / 命令）
cxlogin                # 登录（没配账号时会引导输入手机号/密码）
cxsetphone 13800000000 # 设置手机号
cxpwd 你的密码          # 设置密码
cxaccount              # 查看账号与登录状态（别名：账号 / cxstatus）
cxlogin 密码|短信|cookie|auto
cxcode 123456          # 提交验证码（短信/图形通用）
cxsetcookie <cookie>   # 提交 Cookie 登录
cxbind                 # 绑定当前会话接收提醒
cxunbind               # 解绑当前会话
cxcheck                # 立即巡检一次
```

课程名匹配规则：先按序号，再按名称包含（`高等数学`），最后按逐字顺序模糊匹配（`高数` → `高等数学`），命中多个时取名字最短的。

课程列表有 10 分钟内存缓存，避免每次查询都重新登录拉页面（也降低风控概率）。

## 注意事项

- 学习通**没有官方开放 API**，本插件使用社区逆向的非官方接口（登录/课程/作业思路参考 DanMo661/xuexitong-cli、chaoxing-mcp、学习通 APP 逆向等开源成果，2026 年实测可用）。若学习通改版导致解析失败，需要更新 `chaoxing_api.py`。
- 请在正常频率下使用，巡检间隔不要太短，以免触发风控。
- 若账号触发人机校验/双因子，需要在手机或网页端人工通过一次。
- 账号密码保存在 AstrBot 配置中、Cookie 保存在 `data/plugin_data/astrbot_plugin_chaoxing_ddl/data.json` 中，请勿把这两个文件泄露给他人。
- 插件不做任何「提交作业」操作，只读。

## 有作业没被提醒到？（无时间限制的预习作业等）

- **无截止时间的作业**：详情页没有「作答时间」，插件按「无时间限制/未知」处理，`作业` 和每日汇总里都会列出，只是不会触发「剩 N 天」的定时提醒（没有时间就没有提醒节点）。
- **状态识别范围**：`未交 / 未提交 / 待提交 / 待做 / 未做 / 未完成 / 待完成 / 未开始 / 待开始 / 待作答 / 待批阅 / 进行中` 都算未完成。学习通若返回别的叫法，发「**作业 全部**」能看到每条的状态原文，把原文告诉插件作者即可补充。
- **章节内的任务**：预习/测验如果是挂在课程目录（章节任务点）里的，不会出现在学习通的「作业列表」接口里，这类暂时抓不到；发「作业 全部」若完全找不到该条目，基本可确定是这种。

## 常见问题

**覆盖安装后报 `ImportError: cannot import name 'LOGIN_MODE_AUTO'`**

这是模块缓存问题，不是代码缺少常量。旧版本安装失败时，AstrBot 只清掉了插件主模块，
同目录的 `chaoxing_api` 仍留在 `sys.modules` 里，覆盖安装新版时 Python 会直接复用旧模块。

v0.3.1 起 `main.py` 改为**按文件路径加载** `chaoxing_api.py`（使用插件专属模块名，
并在加载前清掉同名残留），不会再有这个问题。若仍遇到，重启一次 AstrBot 即可彻底清空缓存。
